# OpenSLA: Sensor-Language-Action Models

[![arXiv](https://img.shields.io/badge/arXiv-2610.08244-b31b1b.svg)](https://arxiv.org/abs/2610.08244)
[![Project page](https://img.shields.io/badge/Project-page-664cbc.svg)](https://tennis-rabbit.github.io/OpenSLA/)
[![Models](https://img.shields.io/badge/%F0%9F%A4%97-Models-ffd21e.svg)](https://huggingface.co/yang-ai-lab/OpenSLA)

**Yuekai Xu\*, Zitao Shuai\*, Yuzhe Yang** · University of California, Los Angeles · \*equal contribution

Sensor-Language-Action (SLA) modeling connects multimodal sensor observations, natural language, and actions within a unified model, using language as a semantic interface between sensing and acting. OpenSLA is a unified SLA model for hierarchical action prediction, state understanding, and action explanation, evaluated on clinical care, operating rooms, and metabolic health.

This repository hosts the source of the [project page](https://tennis-rabbit.github.io/OpenSLA/). Code is coming soon.
